# Ecological Information

This directory contains three independent local Git repositories:

- [EIRKB](EIRKB/README.md): ecological information research, theory and reference registers.
- [EII](EII/README.md): ecological variables and indicator inventory.
- [AMRKB](AMRKB/README.md): agricultural modes, methods, practices and technologies.

Open an individual directory for project work, or this containing directory for coordination. The containing directory is outside Git; these are independent repositories without submodules or configured remotes.

## Reorganisation — 12 October 2026

The five original files were moved according to the mapping proposed in “Ecological Information Overview”. Their contents are unchanged. REORGANISATION.json records the original names, destinations, byte sizes and SHA-256 checksums.

The original EIRKB README includes an earlier instruction to retain the filename EIRKB_README.md. The subsequent repository mapping supersedes that filename instruction with EIRKB/README.md; its historical text remains preserved verbatim. Both spreadsheet filenames remain unchanged.

Each project has its own README, Codex instructions and initial local Git commit. No GitHub repository has been created and nothing has been pushed.
